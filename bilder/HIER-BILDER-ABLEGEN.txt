BILDMATERIAL DER KARRIERESEITE
==============================

Alle benötigten Dateien liegen bereits in diesem Ordner. Die Seite erkennt sie
automatisch – es muss kein Code angefasst werden.

  logo.png                        Original-Logo (Navy/Grau), Kopfzeile
  logo-weiss.png                  Original-Logo (weiß), Hero und Footer
  hero.jpg                        Hintergrundbild im Hero (fürs Web komprimiert)
  og-bild.jpg                     Vorschaubild beim Teilen (1200 x 630)

  zerspaner-mit-teil.png          Quellfoto, unverändert
  zerspaner-produktionsleiter.png Quellfoto, unverändert

AUSTAUSCHEN
Eine Datei einfach unter demselben Namen ersetzen. Für ein neues Hero-Foto:
als hero.jpg ablegen, quer, ca. 1800 px breit, unter 300 KB. Bitte keine
mehrere MB großen PNGs direkt einbinden – das kostet auf dem Handy Ladezeit
und damit Bewerbungen.

LOGO
Das Original-Logo wird unverändert verwendet: nicht nachbauen, nicht
einfärben, Seitenverhältnis nicht verzerren.
