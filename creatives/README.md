## Verlinkung der Anzeigen

Damit der Auswahlschritt im Formular entfällt und der Hero auf die Stelle
getextet wird, die Anzeigen direkt auf die jeweilige Stelle verlinken:

* Serienfertigung: `https://saviold.github.io/fluro/?stelle=star`
* Einzelteilfertigung: `https://saviold.github.io/fluro/?stelle=traub`

Ohne Parameter landet der Bewerber auf der Übersicht und wählt die Stelle
selbst – das ist ein Schritt mehr.
